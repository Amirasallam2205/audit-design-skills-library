# Pendo CoE Best Practices — Guide Creation Process

All Pendo guides at Thomson Reuters follow this 4-step process before publishing.

---

## Step 1: Define strategy

Before designing or building anything, establish:

- **Guide initiative:** Identify the category — Onboarding or Features
- **Target users:** Define the audience (e.g., new users, power users)
- **Triggers:** Determine when the guide fires — time-based or audience-based
- **Segmentation:** Define targeting rules using behaviors and attributes

> **Review implication:** If a guide is shared for review without clear targeting intent, flag this. Ask: Who is the audience? What triggers this guide?

---

## Step 2: Collaborate & build

Three functions are involved in building guides:

- **New creators:** Use approved templates and workflows (from the TR Pendo Guides Library and Ready-to-Review Figma files)
- **UX Design:** Owns messaging and design system compliance (Saffron standards)
- **Engineers:** Configure and embed the guide in the product

> **Review implication:** Guides should be built from approved templates. If a guide deviates from the TR Pendo Guides Library patterns, flag it as a potential non-standard build.

---

## Step 3: Test guide

Before requesting approval:

- **Push to staging:** Guide must be tested in a staging environment first
- **Segment (optional):** Can be tested with a limited audience segment
- **Modify as needed:** Iterate based on testing results
- **Status must be: Draft** at this stage — not published

> **Review implication:** If someone is asking for a review of a guide that hasn't been tested in staging, note that Step 3 should happen before Step 4 approval.

---

## Step 4: Approve & publish

- **Pending review:** Guide enters review state
- **Notify reviewers:** Reviewers must be explicitly notified
- **All approved:** All required approvals must be obtained before publishing
- **Publish options:**
  - Manual (immediate)
  - Scheduled timeline (set publish date/time)

> **Review implication:** When reviewing a guide at this stage, confirm that all content, design, and structural standards have been met. A guide should not move to "Publish" until it passes review against TR Pendo Guides Library specs, Ready-to-Review template standards, and Saffron content standards.

---

## Where this fits in the skill workflow

When a user asks for a review, consider asking which step they're at:

- **Step 1–2:** Focus on strategy alignment, template selection, and content drafting
- **Step 3:** Full review pass — content, copy, structure, word list
- **Step 4:** Final sign-off check — confirm everything is publish-ready
