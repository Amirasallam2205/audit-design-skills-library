# Word List Reference

Use this list when choosing vocabulary for error messages. Prefer approved terms and avoid banned words.

---

## Words to avoid (and what to use instead)

| Do not use | Use instead | Notes |
|------------|-------------|-------|
| **invalid** | unrecognized, not valid | Core banned word for error messages |
| **fatal** | — | Core banned word — never use |
| **forbidden** | — | Core banned word — never use |
| **fail / failure** | couldn't, wasn't able to | Avoid in all error copy |
| **error** (standalone label) | Be specific | "Something went wrong" > "Error" |
| **please** | — | Remove to stay concise. Exception: system-caused inconvenience |
| **sorry** | — | Remove to stay concise. Exception: system-caused inconvenience |
| **click** | select | Device-agnostic |
| **submit** | Something specific | Use the user's goal: "Create account," "Send message," "Save" |
| **log in / log out** | sign in / sign out | TR standard |
| **sign into** | sign in to | Two words |
| **webpage / website** | page | Shorter and cleaner |
| **and/or** | or | Pick one |
| **e.g.** | for example | Spell it out |
| **i.e.** | such as, that is | Spell it out |
| **etc.** | and more | Consider rewriting |
| **blacklist** | blocklist | Inclusive language |
| **whitelist** | safelist | Inclusive language |
| **master** | primary, controller | Inclusive language |
| **slave** | secondary, replica | Inclusive language |
| **disable** (for inactive UI) | "not available," "Complete X to enable Y" | OK for admin actions only |
| **see** | Open, Read, Go to, View | Be specific |
| **agent** | expert (support), representative (sales) | TR preferred terms |
| **software** | application | TR preferred |
| **preferences** | settings | More industry-aligned |

## Approved terms for common UI actions

| Word | Usage |
|------|-------|
| **select** | Interacting with a UI element (button, checkbox, option) |
| **choose** | Picking from options or making a decision |
| **enter** | Inputting text into a field |
| **sign in / sign out** | Authentication actions (not "log in") |
| **delete** | Permanently removing an item from the system |
| **remove** | Breaking an association between two items |
| **cancel** | Dismissing without applying changes |
| **close** | Dismissing a passive message or informational modal |
| **OK** | Acknowledging a warning (not "ok" or "Ok") |
| **save** | User must explicitly preserve input |
| **done** | System saves input automatically |
| **next** | Steps in a linear flow |
| **continue** | Nonlinear or open-ended actions |
| **back** | Going to previous step (not "previous") |
| **go back** | Undoing or cancelling an action |
| **upload** | Sending a file from local device to the system |
| **download** | Saving a remote file directly to a local device |
| **export** | Converting information from one app for use in another |
| **edit** | Making changes to a specific item |
| **clear** | Resetting elements to their default state |
| **show / hide** | Revealing or collapsing content |
| **add** | Creating an association or adding something new |
| **duplicate** | Creating a copy of an item in the same location |

## Approved terms for support and contact

| Word | Usage |
|------|-------|
| **Support** | Acceptable with or without "expert" — refer as a group when possible |
| **expert** | TR's preferred term for customer support staff |
| **representative** | Use for sales positions only |
| **Help and Support** | TR's help center — capitalize as shown |

## File types and sizes

- File type extensions in **ALL CAPS** when referring to the type: PDF, DOC, CSV, XLSX
- File type extensions in **lowercase** when part of a filename: `budget_template.xlsx`
- File sizes always include a space: **25 MB** (not 25MB)

## Point of view

| Pronoun | When to use |
|---------|-------------|
| **you / your** | Addressing the user directly — default voice |
| **we / our** | Referring to the system or company |
| **they / their** | Singular pronoun when gender is unknown |
| **me / my / I** | Avoid — don't take the user's point of view |

**Exception:** "you / your" can imply blame — use passive voice or "we" when the error is not the user's fault.

| Do | Don't |
|----|-------|
| We couldn't recognize that password. | You entered an incorrect password. |
| Something went wrong. Try again. | You caused an error. |

## TR-specific terms

| Term | Usage |
|------|-------|
| **Thomson Reuters** | Use "we" or "our" instead when possible |
| **tr.com** | Use in written content instead of thomsonreuters.com |
| **sign-in** (noun/adj) | The place where users authenticate |
| **sign in** (verb) | The act of authenticating |
| **setup** (noun) | A location or configured state |
| **set up** (verb) | The act of configuring |
| **email** | No hyphen; not "e-mail" |
| **username** | One word; not "user name" |
| **homepage** | One word |
| **admin** | OK to abbreviate "administrator" |
| **app** | OK to abbreviate "application" |
| **info** | OK in labels/buttons; use "information" in body copy |
| **canceled / cancellation** | Not "cancelled" or "cancelation" |
| **sync** | Not "synch"; past tense "synced" |
| **eSignature** | Not "e-signature" or "esignature" |
| **two-factor authentication (2FA)** | Not MFA or two-step verification |
| **promo code** | Not "discount code," "coupon code," etc. |
| **read-only** | Hyphenated; for restricted edit state or permission level |
